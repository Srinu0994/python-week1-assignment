# Screenshots Directory

This directory contains placeholders and guides for capturing mandatory UI/CLI execution screenshots for the Week 1 assignment evaluation.

## Required Screenshots Checklist

1. `01_student_management_main_menu.png`: Student Management System main menu interface.
2. `02_student_add_view_update.png`: Successful student creation, list view, and update execution.
3. `03_expense_tracker_summary.png`: Expense Tracker summary report output and category breakdown.
4. `04_error_handling_demo.png`: Graceful input validation handling (e.g. invalid dates, non-numeric marks/amounts).
5. `05_mini_challenges_execution.png`: Terminal output of running string, list, and dictionary challenge scripts.

## Capture Instructions
To take screenshots of your terminal:
- **Windows**: `Win + Shift + S` or Snipping Tool.
- **Mac**: `Cmd + Shift + 4`.
- **Linux**: `Spectacle` or `Gnome Screenshot`.

Save all captured images into this `screenshots/` directory before committing to GitHub!
